# El Bibliotecario

Biblia de diseño de **El Bibliotecario** (*The Librarian*), un RPG de fantasía con combate por turnos y defensa reactiva (la Réplica), mundo interconectado y reconstrucción de un reino partido en cinco dimensiones.

- **Leer en la web:** https://ramirezab.github.io/el-bibliotecario/
- **Empezar por:** [00_INDICE.md](00_INDICE.md) y [01_CANON.md](01_CANON.md) (fuente de verdad).

| Carpeta | Contenido |
|---|---|
| `historia/` | Trama, personajes, NPCs y misiones |
| `lore/` | Historia del reino, misterios, reliquias, textos del mundo, ideas de expansión |
| `mundo/` | Zonas, los cinco Pliegues y Las Entrañas (con diálogos completos) |
| `guion/` | Prólogo, Acto I, interludios y final |
| `sistemas/` | Combate, progresión, Semillados, economía |
| `arte/` | Dirección de arte y biblia de efectos visuales |
| `produccion/` | Plan de desarrollo |
